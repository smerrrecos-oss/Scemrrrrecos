## Typography Scale
- Headlines (Hero): Very large, bold, dark brown (~48-64px)
- Section Headlines: Large, bold, dark gray (~32-40px)
- Body Text: Medium, regular weight, dark gray (~16-18px)
- Small Text: Small, regular weight, lighter gray (~14px)
- Button Text: Medium, bold, uppercase, white (~14-16px)

## Color Tokens (approximations)
- Primary Dark: #2D2926 (dark brown)
- Primary Green: #1B4332 (dark green, footer/services)
- Text Dark: #2D2926 (dark gray/brown)
- Text Light: #666666 (medium gray)
- Background Light: #F5F5F0 (light beige/cream)
- Background White: #FFFFFF
- Button Dark: #2D2926 (dark brown/gray)
- Button Green: #1B4332 (dark green)
- Accent: White for buttons/icons

## Spacing Scale
- Container Max Width: ~1440px
- Section Padding: 80-120px (desktop), 24-40px (mobile)
- Card Gap: 24-32px
- Button Padding: 16px 32px
- Element Gap: 16-24px

## Grid Rules
- Desktop: Max-width container, centered
- Cards: 4 columns (desktop), 1 column (mobile)
- House Types: 1 column stacked (desktop shown), responsive to grid

## Component Inventory
- Header with logo, nav menu, phone, CTA button
- Hero section with headline, description, CTA
- Feature cards (dark green background, white text)
- House type cards (light background, dark text, image, button)
- FAQ accordion (dark gray, expandable)
- Footer (dark green background, white text)
- Buttons (dark/green, rounded corners, arrow icon)
- Navigation arrows/carousel controls
